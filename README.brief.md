# Less AI Tone

去 AI 味 — 按可验证的规则清理中文写作里的机器痕迹。

## 从语感到证据

"AI 味"是个人人都能感觉到、却没人说得清的东西。社交媒体上流传着各种判断清单。破折号太多算一条，动不动"不是 A 而是 B"算一条，还有句子长得一模一样、缺"就/很/了"这类虚词。也有人说 AI 爱用"仓库""温度"包装抽象概念，爱自问自答。这些说法反复传播，逐渐变成常识。

其中有些是真的。破折号确实是 AI 的三倍，"不是 A 而是 B"三点四倍，这两条留在了规则里。

但没人分清哪些是真的。

这个项目把 629 篇文章放进了同一套统计流程，283 万汉字、95,551 个句子、45,721 个段落。一半是五个主流模型（Claude、DeepSeek、Gemini、GPT、Kimi）在同一批话题下的输出，一半是真实中文作者的公开文章。然后逐条去数那些被称为"AI 味"的句式，看人类用得多，还是机器用得多。

| | 篇 | 汉字 | 句 | 段 |
|---|---|---|---|---|
| AI | 300 | 1,179,105 | 37,642 | 14,549 |
| 人类 | 329 | 1,647,867 | 57,909 | 31,172 |

最初列了二十多条预设，逐条测下来，**十五条被推翻**。

## 怎么测的

结论好看不如方法站得住，所以先说方法。

**控制变量。** 两侧的话题范围和文体保持对齐。如果两边写的不是一类东西，测出来的差异就分不清是模型造成的还是文体造成的。AI 侧不联网、不给写作指令，只给话题，否则测不出模型的默认倾向。

**五个模型，不是一个。** 早期只用两个模型 30 篇，结论后来被推翻大半。"破折号是 Claude 独有"就是这么来的，扩到五个模型才发现 DeepSeek 更重。单个模型的癖好很容易被误读成 AI 的共性。

**人类侧分组独立算，再看组间是否一致。** 某一项如果只在个别组偏高，那是个人风格或文体特征，不是人类共性。虚词和破折号都是这样被识破的，破折号在组间差了一百倍，从 0.01 到 1.29。

**分母按测什么选。** 词汇和标点用每千汉字，段落结构用每百段，依附于特定结构的用占比。这一条最容易出错。AI 平均每篇 10 个小标题，人类 1-2 个，用每千字算问句小标题是 32 倍，换成占小标题的比例就没有差异。前者测的是"AI 小标题多"，后者才是"AI 爱用问句当小标题"。

**收录门槛。** 倍率 2 倍以上收，1.25 到 2 倍要求人类侧稳定且量足够大，0.8 到 1.25 算无差异。除此之外还要满足两条，触发标记能定位到具体某句某词，改法不违反白名单。所以"比喻贴不贴切"这类语篇特征一律排除，哪怕感觉上很像 AI 味。

**已知的缺陷。** 语料不入库，所以下面的数字第三方无法核验；正则匹配字面形态而非语义，写宽了会抓错，本项目为此翻过六次车。完整的切分规则、判定标准和正则定义见 [RESEARCH.md](./RESEARCH.md)。

## 十五条不成立的"AI 味"

倍率是"AI ÷ 人类"。要能立为规则，AI 得明显多于人类。

| 常见说法 | 实测 | 倍率 |
|---------|------|------|
| AI 句长过于均匀（差 50 倍） | 句长变异系数 AI 0.58、人类 0.67 | 0.87× |
| AI 相邻句长变化小 | AI 21.7、人类 21.7 | 1.00× |
| AI 段落长度也极均匀 | 稳健离散度 AI 0.94、人类 1.00 | 0.94× |
| AI 缺"就/很/了"这类虚词 | "就"AI 2.93、人类 6.45 | 0.45× |
| AI 缺"但是/其实/不过" | AI 1.01、人类 3.87 | 0.26× |
| AI 反复写全称、少用代词 | 相邻句同名词开头 AI 0.02、人类 0.04 | 0.5× |
| AI 爱写被动句 | 抽象被动 AI 0.09/千字 | 低于门槛 |
| AI 爱自问自答 | AI 0.13、人类 0.13 | 1.03× |
| AI 爱用问句当小标题 | 占小标题比例 AI 2.7%、人类最高 3.6% | 0.75× |
| 该删掉正文里的设问 | AI 0.10、人类 1.83 | **0.05×** |
| AI 爱用三连排比 | 句内同字排比 AI 2.35、人类 3.87 | 0.61× |
| AI 爱用比喻包装抽象概念 | 比喻标记词 AI 0.16、人类 0.38 | 0.42× |
| AI 爱让抽象名词做具体动作 | "时间保管细节"类 AI 0.001、人类 0.001 | 0.7× |
| AI 爱把动词写成名词 | "完成了对…的优化"AI 0.003、人类 0.005 | 0.52× |
| GPT 29% 段落用"首先/其次"开头 | 句首"首先，"AI 0.06、人类 0.03 | 2× 但量极小 |

有三条不只是"没差异"，而是方向完全相反。

**比喻。** 所谓"AI 爱用比喻装深刻"，数据上反过来。人类用比喻是 AI 的 2.4 倍，独立成段起一个意象更是 8 倍。真正的差别不在用不用比喻，而在拿什么当喻体。AI 偏爱"像一位智慧的导师""一个永不疲倦的审查员"这类理想化的职业人格（7.3 倍），人类写的是"像一个老师傅""像一个人脉很广的医生朋友"。一个在抒情，一个在说事。

**问句。** 正文里的设问，人类是 AI 的 17 倍。按"删掉问句"这条流行建议改，会把文本推向更不像人写的方向。

**句长均匀。** 这个说法本项目最初也信，还给过一个 ×51 的倍率。后来发现是切句程序有缺陷。它只按句号感叹号问号断句，Markdown 表格和没有句号的长列表就被当成了一个句子，某个样本的标准差因此算成均值的 27 倍。修正后重测 0.87 倍，没有差异。

## 十一条留下来的规则

| | 规则 | 实测 | 倍率 |
|---|------|------|------|
| 1 | 翻案腔（"不是 A 而是 B"） | AI 0.73、人类 0.22 | 3.4× |
| 2 | 顿号罗列过密 | AI 3.21、人类 1.78 | 1.8× |
| 3 | 相邻句结构同款 | 每百段 AI 9.41、人类 4.81 | 2.0× |
| 4 | 破折号滥用 | AI 2.38、人类 0.80 | 3.0× |
| 5 | 提示性冒号（"核心是："） | AI 0.32、人类 0.08 | 4.2× |
| 6 | 序数词当小标题（"一、二、三"） | AI 0.19、人类 0.06 | 3.1× |
| 7 | 拟人化喻体（"像一位智慧的导师"） | AI 0.018、人类 0.002 | 7.3× |
| 8 | 用概括盖掉原文已有的具体数据 | 数字密度 AI 6.34、人类 17.92 | 人类 2.8× |
| 9 | 起手式（"说白了"） | AI 0.025、人类 0.008 | 3.2× |
| 10 | 翻译腔（18 种筛到 5 种） | 见下 | 2.6-5.3× |
| 11 | 段首零主语评论（"听起来像…"） | 占非首段 AI 0.61%、人类 0.14% | **4.4×** |

每条都有可定位的触发标记，能数出来，能指出在第几句，能机械判断。不写"读起来太整齐"这种没法验收的话。

倍率最高的第 11 条也最出人意料。AI 味最重的地方不在标点或句长上，而在段落之间的接缝。AI 起一个新段落时常常直接抛出评论，"听起来像一条功能描述""值得注意的是"，不交代评论的对象，读者得回上一段找。补一个"这"字就接回来了。段首衔接词的总量其实没差异（AI 14.4%、人类 15.1%），问题只在评论句省掉了回指。

### 翻译腔：18 种筛到 5 种

一开始按"英文句法照搬"列了十八种。测完只剩五种够格，其余十三种是翻译腔但不是 AI 痕迹，现代汉语书面语本来就这么写。

| 收录 | AI 每千字 | 淘汰 | AI 每千字 |
|------|-----------|------|-----------|
| 过长前置定语 | 0.42 | 被动-抽象（"被认为"） | 0.09 |
| "当…时"从句 | 0.26 | "在…的过程中" | 0.07 |
| 前置话题壳（"对于…来说"） | 0.22 | "不仅仅是" | 0.05 |
| 句首连接词（"然而，"） | 0.18 | "存在着/有着" | 0.04 |
| "这意味着"式复述 | 0.15 | "进行了…的分析" | 0.03 |
| | | "使得…能够" | 0.03 |
| | | "扮演…角色" | 0.02 |
| | | "在某种程度上" | 0.02 |
| | | "值得注意的是" | 0.02 |
| | | "以一种…的方式" | 0.01 |
| | | "一系列的" | 0.00 |

被淘汰的里面有三种是本项目最初版本自带的规则。"以一种…的方式""使得…能够""扮演…角色"，实测都在 0.03 以下。

### 模型之间差得比想象大

| 特征 | Claude | DeepSeek | Gemini | GPT | Kimi |
|------|--------|----------|--------|-----|------|
| 破折号 | 4.25 | **5.16** | 0.51 | 0.11 | 2.32 |
| 提示性冒号 | 0.38 | **0.43** | 0.22 | 0.25 | 0.32 |
| 不是…而是 | 0.61 | 0.86 | 0.29 | **1.26** | 0.51 |
| 序数词小标题 | **1.00** | 0.69 | 0.22 | 0.73 | 0.82 |
| 过长前置定语 | 0.64 | **0.65** | 0.48 | 0.06 | 0.22 |
| 问句小标题 | 0.043 | 0.086 | **0.173** | 0.008 | 0.000 |

破折号最重的是 DeepSeek 不是 Claude，而 GPT 只有 0.11，同一个特征差四十倍。所以别按"某个模型的味"去套，只按触发标记逐句认。

GPT 破折号这么低，也有人据此说破折号已经不算 AI 痕迹了。但 Claude 是人类的五倍多，而写作场景里 Claude 用得很广，所以这条保留。

### 和英文研究对不上的地方

《经济学人》2026 年 7 月做过一次类似研究（55,940 句、120 万词，对比 ChatGPT/Claude/Gemini/Grok），结论是 AI 标点偏少。中文语料只有一半成立。

| 指标 | AI | 人类 | 与英文研究 |
|------|-----|------|-----------|
| 逗号 | 39.39 | 56.78 | 一致（AI 少） |
| 短句率（≤15 字） | 14.9% | 18.4% | 一致（AI 少） |
| 抽象后缀词（性/化/度/主义） | 8.61 | 5.28 | 一致（AI 多） |
| 分号 | 1.64 | 0.95 | 相反 |
| 括号 | 3.50 | 2.10 | 相反 |
| 引号 | 14.65 | 4.87 | 相反 |

引号差异最大且方向相反。那篇研究认为 AI 引号少是因为"不引用专家"，但中文语料里 AI 引号是人类的三倍，因为它爱写虚构对话。"不引用"这件事在中文里换了个形式。数字密度只有人类的 36%，时间锚点 39%。这条成了第 8 条规则的依据。

## 白名单，不是黑名单

改写只在清单内进行。没命中规则的句子逐字保留。标题层级和段落顺序不动，列表、表格、代码块也不动。

还有一条更硬的规则，**信息守恒**。绝不新增姓名、数字、日期、引语、来源、因果或任何原文没写的细节；也不删观点、结论和限定词。把"可能提升"改成"提升"是篡改判断强度，不是去 AI 味。改写后每个实词都要能在原文里指出出处。

判断不了的事不做。比喻贴不贴切，问句是否解决了真实疑问，三个案例是不是在凑数，这些都得靠人读，写成规则只会让模型凭语感乱改。

完整规则见 [SKILL.md](./SKILL.md)，数据和被推翻的预设见 [RESEARCH.md](./RESEARCH.md)。

## 用法

```bash
npx skills install lieflat-less-ai-tone -g    # 全局
npx skills install lieflat-less-ai-tone       # 项目级
```

安装后丢一段中文进去。也可以直接把 `SKILL.md` 当 system prompt 用，适配任何支持自定义 prompt 的工具。

配合风格蒸馏用的话，[writing-dna-skill](https://github.com/larashero3-dotcom/writing-dna-skill) 负责让文字像目标作者，这个 skill 负责让它不像机器。蒸馏出 Writing-DNA，按 DNA 写作，最后清一遍痕迹。同目录有蒸馏产物时先读 `语言DNA.md`，**冲突时以蒸馏产物为准**：那是作者的真实写法，不是 AI 痕迹。

## 自己测一遍

```bash
# 句级：各规则在人类与 AI 语料的命中率
python3 scripts/compare-human-ai.py --human <目录...> --ai <目录...>

# 段落级：句子同构、段首零主语
python3 scripts/check-structure.py --human <目录...> --ai <目录...>

# AI 侧：翻译腔各句式频率
python3 scripts/check-translationese.py <目录...>
```

有个教训值得写出来。这个项目在测量上翻过六次车，每次都是拿宽泛的正则去测一条有精确定义的规则，然后信了结果。

| 第一次测出 | 问题 | 重测后 |
|-----------|------|--------|
| 长前置定语 3.04/千字 | 正则把普通句子也算进来 | 0.35 |
| 并列连词 0.26 | 规则说"一句内两次以上"，测的是单个"而且" | 0.00 |
| "的…的…的"连用 0.25 | 跨顿号匹配，把正常并列算成嵌套定语 | 0.06 |
| 提示性冒号无差异 | 6431 处命中里标题 1266、列表 1225、对话 207 | AI 是人类 4.2 倍 |
| 问句小标题 32 倍 | 分母用字数，而 AI 每篇小标题是人类的 5-10 倍 | 无差异 |
| 比喻包装 0.000 | 正则是写死的十一词表，真实比喻一个都不在表里 | 人类是 AI 的 2.4 倍 |

所以：**先抽样看 20 条命中，再看频率。** 涉及小标题、段落这类结构元素的指标，分母必须是同类元素的总数，不能用字数。

这些数字还都有保质期。模型每次更新都在向人类文风靠近，GPT 的破折号从"几乎每句一个"降到 0.11 只用了不到一年。
