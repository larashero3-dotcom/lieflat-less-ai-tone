# 语义层判据（四项）

检测分三层分工：数得出符号的归脚本（detect.py），要理解句意的归语义层（本文件，由会话内 Claude 逐条判断），机器间共识不够的归人审（比喻贴切度，见 SKILL.md 人审区）。

用法：先跑 `python3 scripts/detect.py <文件> --candidates --out <候选.json>`，对候选里的每一条按对应判据给出封闭标签（只能从判据列出的标签中选）+ 置信度（高/中/低）+ 一句话理由。判断完把 `label`/`confidence`/`reason` 三个字段写回该条候选，供 report.py 汇总。

**判断纪律**（来自 43 万次打标的教训）：
- 只按判据判，不按「像不像 AI」的整体感觉判——整体印象会被文风糊弄
- 每条独立判断，不看全文来源（候选里故意不给全文，防止模型靠整体文风猜）
- 拿不准就选判据里的兜底标签，不硬判
- 标签只能从该条判据列出的集合中选，禁止自造标签

---

## 1. 同义重命名（段级）——第一层第 2 条，最强可操作信号

**背景**：同一实体/概念在段内换实义说法，读者要做「X 就是 Y」的等同连接。AI 0.83-0.86 次/段 vs 人类 0.49；≥2 次的重灾段 AI 20.6-22.5% vs 人类 8.4%。**证据注记：Jev 单模型一轮判据，跨模型同向但判据未迭代，稳健性弱于其他三项，复测时优先重跑。**

**候选**：每段一条（`para` 字段）。

**判据**（对每段数「换实义说法」的连接次数；代词、省略不算）：

| 标签 | 判据 |
|---|---|
| 0组 | 段里每个实体/概念从头到尾用同一个（或字面几乎相同的）说法指称，或只出现一次，不存在换说法 |
| 1组 | 有一个实体/概念在段内换了 1 次实义说法，读者需要做 1 次「X 就是 Y」的等同连接 |
| 2组 | 有两个实体/概念各换了说法，或同一个换了 2 次 |
| 3组及以上 | 换说法的连接次数 3 次或更多 |
| 无法判断 | 段落无法分析 |

**典型例**：同一段里「优化／增强／提升／提高」轮着用；「版图→基地→项目→节点→本地制造安排」五个名字叫同一个电池工厂项目。人类会反复用同一个词。

**改写方向**（确认后）：同义链统一回原名词——零信息损失，人类范本即反复用原名的写法。

## 2. 衔接方式（段间接口）——第一层第 7 条

**背景**：AI 段段紧扣（明确承接 98.9% vs 人类 95.2%），人类自然跳跃（主题跳转 7.2% vs AI 2.1%）。真正差异不是承接词频率（两侧都低，无害），是**零跳转的背景概率**：≥6 连环 AI 93% 的文章有。连环数的是接口数不是段落数。

**候选**：每个段间接口一条（`prev_tail` = 上段末句，`next_head` = 下段首句）。

**判据**（判 a=prev_tail 到 b=next_head 的衔接方式；若 b 句首有连接词，先检查连接词标示的逻辑关系是否真的成立）：

| 标签 | 判据 |
|---|---|
| 表面有连接词实际关系不清 | b 开头用了连接词（但是/因此/于是/与此同时等），但读完 b 会发现连接词标示的逻辑关系并不成立或很勉强。**优先检查这一条** |
| 明确承接 | 前后围绕同一对象或同一论述关系继续展开，衔接自然，允许用同义词、代词、省略，不要求重复字面词语；有连接词时其逻辑关系也确实成立 |
| 有关但转换突然 | 前后确实有关联（同一话题域），但衔接方式突兀，中间缺了一步过渡，读者需要自己补上跳过的逻辑 |
| 主题跳转缺少说明 | b 换到了和前面基本不相关的新话题，没有任何衔接说明 |
| 无法判断 | 上下文不足以判断 |

**统计口径**：连续「明确承接」的接口数为连环长度；≥6 连环即报告（AI 短文中位 7 连环 vs 人类 2）。

**改写方向**（确认后）：在连环中选 1-2 个接口改成自然跳跃/断裂（人类话题跟着信源走，不替读者预先铺垫）；有连接词但不成立的接口优先处理。

## 3. 冒号分类——第一层第 6 条

**背景**：冒号总量人类反而多（δ−0.37/−0.31），只有「结论提示」子类是 AI 2.1-2.2 倍的真信号；「空转提示」反向（人类多一个量级）。

**候选**：正文每个冒号句一条（`colon_before` / `colon_after` / `sentence`）。

**判据**（按优先级从上往下判，命中即停）：

| 标签 | 判据 |
|---|---|
| 引语或人物发言 | 冒号前是人名/称呼+访谈体发言格式，或有「说/表示/写道/提出/宣布」等引出言论的词且紧跟该人物主语。**优先于其他类别** |
| 标题时间比例元数据或版式用途 | 冒号前是标题结构/时间戳/比例数字/来源作者等版式元数据（访谈体「人名：发言」不算，那属上一类） |
| 定义或解释 | 冒号前是术语/概念/功能名称，冒号后给出该术语的定义或具体内容 |
| 空转提示 | 冒号前只是空洞宣布「下面有几点」，不含论断，冒号后是纯列举。**已否决项：人类更多，不改** |
| 结论提示 | 冒号前给出一句独立、明确的结论性判断（含「是/在于/取决于/意味着」等论断谓语），冒号后是对这个结论的展开论证。**唯一真信号** |
| 其他正文冒号 | 不属于以上任何一类的正文冒号，默认落点 |
| 无法判断 | 上下文不足以判断。不要为了给出答案而滥用这一类 |

**典型例**：「这组数字传递出一个残酷的现实：……」——结论宣告+展开。

**改写方向**（确认后，只动「结论提示」类）：删提示语直接写内容，或前半句承接上文时只换标点。

## 4. 高度同构三连——第二层（指纹，证据强度弱于第一层）

**背景**：连续三句共用同一句式骨架。宽口径（结构相近即算）无区分力（AI 71.1% vs 人类 56.2%），只有**高度同构**档有 2.76× 差异（AI 29.4% vs 人类 10.7%）——AI 是排得更极端（骨架逐字复刻），不是更爱排比。三连里仅 30% 含顿号列举，七成是三连问句/同款长句的纯句法复用。

**候选**：signature 粗筛出的连续三句组（`sents` 字段三句原文）。粗筛宽（部分同构也收），判读收紧。

**判据**（只判这一组三句，不给全文）：

| 标签 | 判据 |
|---|---|
| 高度同构 | 三句的主语、谓语、宾语、补充成分在句子里的位置基本一一对应，句法框架几乎相同，只是填入的具体词不同 |
| 部分同构 | 句法结构有明显相似（比如都用了同样的主谓框架），但只是部分对应，不是每个成分都对得上，或多出/缺了一部分成分 |
| 只有词语重复句法不同 | 句子间重复了某些词或短语，但整体句法组织（谁是主语、谓语怎么摆放）并不相同 |
| 只有语义并列句法不同 | 句子间只是在内容/意思上构成并列关系（讲的是同类的几件事），但句法结构不同 |
| 无同构关系 | 句法与语义并列上都没有明显的重复或对应关系 |
| 无法判断 | 上下文不足以判断，或句子残缺 |

**典型例**：「叫什么名字？／承载什么功能？／嵌入哪个生态？」——句首各异骨架同款。「服务网络能不能覆盖到我春节回老家的那段路？／车的残值能不能经得起检验？／这家公司出了问题谁来管？」——三连问句。

**改写方向**（确认后）：拆掉其中一句（打破骨架复用），不是删掉一项内容。与顿号罗列分界：顿号管句内塞多项，本条管句间共用骨架。

## 汇总口径

判断完四类后按以下口径汇总进报告：

| 指标 | 计算 | 人类参考 | AI 参考 | 显著门槛 |
|---|---|---|---|---|
| 同义重命名 次/段 | Σ(各组标签数) / 段数 | 0.49 | 0.83-0.86 | ≥0.7 或重灾段（≥2组）占比 >15% |
| 衔接连环 | 最长连续「明确承接」接口数 | 中位 2 | 中位 7 | ≥6 连环 |
| 结论冒号占比 | 结论提示 / 正文冒号总数 | 低 | 2.1-2.2× 人类 | 相对比例高即列 B 级 |
| 高度同构三连数 | 「高度同构」标签计数 | 10.7%（占三连组） | 29.4% | 绝对数 ≥2 组即列 B 级 |

四项在 270 对配对语料统计显著（同义重命名为 Jev 单模型判据，稳健性弱于其他三项）。改写仍走 SKILL.md 的白名单+确认流程。
